# Part F – AI Prompt Log

**Project:** Campus Helpdesk Agent  
**Verification date:** 11 November 2026

This log records examples where AI assistance was incorrect, incomplete, or not supported by sufficient evidence during project development.

## Entry 1 – Incorrect folder creation command

**Tool:** ChatGPT

**Prompt/context:** Help me create the required folders for the Skill, Plugin, and MCP project.

**AI output summary:** The assistant provided a `mkdir -p` command with incorrectly formatted line continuations.

**Problem detected:** The command formatting was not suitable for copying directly into the terminal.

**Action taken:** The folder creation instructions were corrected and the required folders were created separately.

**Lesson:** Commands generated by AI should be checked before execution, especially when they contain multiple paths or line continuations.

## Entry 2 – Inconsistent Plugin Marketplace Path

**Tool:** ChatGPT

**Prompt/context:** Help me configure the Claude Code plugin marketplace file.

**AI output summary:** The assistant provided inconsistent instructions about the marketplace file location and relative plugin source path.

**Problem detected:** The suggested paths changed during the conversation.

**Action taken:** The repository structure was reviewed. The marketplace file was placed at `.claude-plugin/marketplace.json`, with the plugin source configured relative to the repository layout.

**Verification limitation:** The marketplace structure was created, but live plugin installation was not verified because the Claude Code CLI was unavailable.

**Lesson:** Relative paths must be checked against the actual directory structure.

## Entry 3 – Missing MCP Inspector Dependency

**Tool:** ChatGPT and terminal

**Prompt/context:** Help me start and test the Python MCP server using MCP Inspector.

**AI output summary:** The assistant provided the launch command but did not initially account for the missing `uv` executable.

**Problem detected:** The terminal returned a `spawn uv ENOENT` error.

**Action taken:** I installed `uv`, verified its availability, and launched MCP Inspector successfully.

**Lesson:** Technical instructions should include environment prerequisites, and terminal errors should be used to identify missing dependencies.

## Entry 4 – Unavailable Claude Code CLI

**Tool:** ChatGPT and terminal

**Prompt/context:** Help me verify whether the plugin can run in Claude Code.

**AI output summary:** The assistant suggested checking the Claude Code CLI using `claude --version`.

**Problem detected:** The terminal returned `claude: command not found`.

**Action taken:** I recorded that live plugin installation and runtime testing could not be completed in this environment. I did not claim that the plugin had been successfully installed.

**Lesson:** Creating plugin files is not the same as testing a plugin in its actual host application.

## Entry 5 – Unverified Package and Command Claims

**Tool:** ChatGPT and official documentation checks

**Prompt/context:** Verify the package `@nimbus/mcp-skill-bridge` version 2.3 and the Claude Code `/worktree-merge` command.

**AI output summary:** These names were considered possible tools or features, but reliable official evidence was not established.

**Problem detected:** No reliable source was found to confirm the exact package/version or that `/worktree-merge` is a built-in command.

**Action taken:** The package and command were treated as unverified rather than claiming that they exist or do not exist. Regular Git merge commands were used for the worktree merge.

**Lesson:** Package names, versions, and command availability must be verified before being included in technical instructions.

## Overall Observation

These examples demonstrate that AI is useful for generating commands, explaining technical concepts, and suggesting project structures, but its output is not automatically reliable. I used terminal errors, directory checks, Git status, and available documentation to identify problems. I corrected unsupported or incomplete instructions instead of treating every AI response as accurate.
