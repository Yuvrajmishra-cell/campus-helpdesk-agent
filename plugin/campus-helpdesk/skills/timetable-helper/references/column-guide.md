# Timetable CSV Column Guide

The timetable CSV contains the following columns:

| Column | Meaning | Example |
|---|---|---|
| Subject | Name of the college subject | Database Management System |
| Day | Day when the class takes place | Monday |
| Batch | Student group attending the class | CSE-A |
| StartTime | Time when the class begins | 09:00 |
| EndTime | Time when the class finishes | 10:00 |
| Room | Classroom where the class takes place | Room 101 |

## How to use the columns

- Use Subject to identify the class.
- Use Day to find classes scheduled on a particular day.
- Use Batch to show the correct timetable for a student group.
- Use StartTime and EndTime to show class timings.
- Use Room to tell students where their class is held.

## Important note

The CSV contains sample timetable data created for this assignment. It may not represent an actual college timetable.
